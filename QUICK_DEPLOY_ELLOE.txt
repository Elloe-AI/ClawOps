STEP 0: DNS CONFIGURATION (DO THIS FIRST!)
================================================================================

Go to your DNS provider for elloe.ai and add:

Type: A
Name: clawops
Value: 143.198.12.229
TTL: 300

Wait 5-10 minutes, then verify:
nslookup clawops.elloe.ai
(Should return: 143.198.12.229)

================================================================================
STEP 1: CONNECT TO SERVER
================================================================================

ssh root@143.198.12.229

================================================================================
STEP 2: RUN AUTOMATED DEPLOYMENT
================================================================================

bash <(curl -s https://gitlab.com/introd1/ClawOps/-/raw/main/scripts/deploy-digitalocean.sh)

When prompted:
- Domain: clawops.elloe.ai
- Email: your-owen@elloe.ai
- Git repo: [press Enter to use default]

================================================================================
STEP 3: GENERATE SECRETS
================================================================================

Run these commands on the server:

echo "SHARED_SECRET_TOKEN=$(openssl rand -hex 32)"
echo "AEAD_SECRET_KEY=$(openssl rand -hex 32)"
echo "NEXTAUTH_SECRET=$(openssl rand -hex 32)"
echo "CLAWOPS_ENGINE_API_KEY=$(openssl rand -hex 32)"

Copy the output for the next step.

================================================================================
STEP 4: EDIT ENVIRONMENT
================================================================================

cd /opt/clawops
nano .env

Required changes:

POSTGRES_PASSWORD=<create-strong-password>
CLICKHOUSE_PASSWORD=<create-strong-password>
CLICKHOUSE_RO_PASSWORD=<create-strong-password>

SHARED_SECRET_TOKEN=<paste-from-step-3>
AEAD_SECRET_KEY=<paste-from-step-3>
NEXTAUTH_SECRET=<paste-from-step-3>
CLAWOPS_ENGINE_API_KEY=<paste-from-step-3>

NEXTAUTH_URL=https://clawops.elloe.ai

OPENAI_API_KEY=sk-your-openai-key-here
# Or use OpenRouter:
OPENAI_BASE_URL=https://openrouter.ai/api/v1

CLAWOPS_ADMIN_EMAILS=admin@elloe.ai

DOCKER_HUB_ORG=clawops
IMAGE_TAG=latest

Save: Ctrl+X, Y, Enter

================================================================================
STEP 5: RECREATE SERVICES (APPLY NEW ENV)
================================================================================

docker compose -f docker-compose.digitalocean.yml down
docker compose -f docker-compose.digitalocean.yml up -d

================================================================================
STEP 6: VERIFY DEPLOYMENT
================================================================================

# Check all services are running
docker compose -f docker-compose.digitalocean.yml ps

# View logs
docker compose -f docker-compose.digitalocean.yml logs -f

# Access ClawOps
Open browser: https://clawops.elloe.ai

================================================================================
USEFUL COMMANDS
================================================================================

# View logs
docker compose -f docker-compose.digitalocean.yml logs -f

# View specific service
docker compose -f docker-compose.digitalocean.yml logs -f frontend
docker compose -f docker-compose.digitalocean.yml logs -f clawops-engine

docker compose -f docker-compose.digitalocean.yml restart

# Update ClawOps
cd /opt/clawops && git pull && \
docker compose -f docker-compose.digitalocean.yml pull && \
docker compose -f docker-compose.digitalocean.yml up -d

# Manual backup
/opt/clawops/scripts/backup.sh

docker stats

curl https://clawops.elloe.ai
curl http://localhost:8006/health
